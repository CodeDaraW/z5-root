- 想查"某个 probe 为什么这么设计" → `grep probeNN 工作日志.md`
- 想看"当时的自我纠错" → 搜 `§19`、`§23`、`§24`、`认账`、`更正`
- **不要**把这里的结论直接当现状：R2 之后（11-11 起）的所有结论都在
